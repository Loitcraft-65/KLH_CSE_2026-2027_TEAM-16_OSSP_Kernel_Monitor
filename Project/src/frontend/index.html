Why This Is a "Kernel Subsystem Monitor" (Not a Task Manager)

Standard tools like Windows Task Manager or Linux top focus on user-space applications (PID memory, window titles). This project inspects the internal machinery of the Linux Kernel (Ring-0):

  • CPU Scheduler Subsystem: Separates Kernel Space (system) from User Space (user), tracking context switch frequency and runnable task queues.
  • SLAB Allocator & Memory: Inspects physical RAM consumed by the kernel object cache (SReclaimable, SUnreclaim, page tables, kernel stacks).
  • Virtual Memory MMU Faults: Differentiates between soft RAM minor faults and severe disk major faults (paging thrashing).
  • Virtual File System (VFS): Tracks allocated kernel file handles against the system-wide ceiling and monitors the dentry cache.
  • Kernel Threads (kthreads): Identifies genuine Ring-0 threads spawned from kthreadd (PID 2) that run without user virtual memory.
